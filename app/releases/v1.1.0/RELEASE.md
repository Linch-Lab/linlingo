# LinLingo v1.1.0

修正第二外語翻譯失效，並改造卡片定位。

## 修正：第二外語翻譯失效

**症狀**：設定「目標語言 英文、第二外語 德文」時，輸入英文沒有翻成德文，
而是原樣輸出或只是換句話說。

**原因**：提示詞把「將以下文字翻譯成英文」寫在第一行當主要指令，
模型直接照做，忽略了後面「原文已是英文時改翻成德文」的條件。

**修法**：讓「**先判斷語言，再決定翻成哪個語言**」成為主要指令，
並明確要求「務必輸出真正的譯文，不要換句話說」。

以真實 API 實測 24 次：

| 提示詞 | 正確率 |
|---|---|
| 舊 | 約 70% |
| **新** | **100%（24/24）** |

延遲不受影響（中位數 0.73 秒，思考模式維持關閉）。

另外加了安全網：若譯文與原文相同（模型照抄），自動開啟思考模式重試一次。

## 變更：卡片位置

**舊行為**：卡片貼在文字游標旁，切換輸入框時跟著移動。
問題是打字、換行、點擊都會讓它跳動，反而干擾閱讀。

**新行為**：

| 情況 | 行為 |
|---|---|
| 開啟時（未曾拖曳） | 置中於目標視窗所在的螢幕 |
| 開啟時（曾拖曳過） | 回到你拖曳到的位置 |
| 使用中 | 完全不移動 |

- 多螢幕：會用**目標視窗所在的那一顆**螢幕，不是主螢幕
- 使用「工作區」置中，不會被工作列遮住
- 新增系統匣右鍵 →「**卡片位置歸中**」可清除記憶回到螢幕中央

> 注意：切換輸入框時「**回填目標**」仍會自動更新（譯文會回填到新點的框），
> 只是卡片本身不再跟著跑。
