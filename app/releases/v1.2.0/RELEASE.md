# LinLingo v1.2.0

卡片外觀可以自己設定了。

## 新增

### 卡片底色

「設定 → 卡片外觀」新增色塊，點擊開啟調色盤。

**外框線會由底色自動推導** —— 選了底色，框線就自己協調，不必再調第二次。
亮色底（例如白色）提亮看不出來時，會自動改為稍微調暗。

### 卡片不透明度

30%～100% 滑桿，即時顯示百分比。預設 88%。

### 卡片圓角

0（直角）～40 像素，預設 14。

Tk 的無框視窗做不出圓角，Windows 的原生圓角 API 也拿不到無框視窗，
因此改用 Win32 `SetWindowRgn` + `CreateRoundRectRgn` 直接裁切視窗區域。

### 即時預覽

「卡片外觀」分頁上方的預覽現在也會反映底色與外框，調整立刻看到結果。

## 設定項目一覽

| 設定 | 範圍 | 預設 |
|---|---|---|
| 卡片底色 | 任意顏色 | `#1c1c28` |
| 不透明度 | 30%～100% | 88% |
| 圓角 | 0～40 像素 | 14 |
| 輸入文字 字級／顏色 | 6～48 / 任意顏色 | 10 / `#b8b8c8` |
| 翻譯文字 字級／顏色 | 6～48 / 任意顏色 | 12 / `#ffffff` |
