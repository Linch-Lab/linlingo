PopLingo

Windows 全域熱鍵即時翻譯工具  ·  v1.0.0  ·  開源免費 (MIT)

下載 特色 快速開始 API 設定 本地部署 常見問題 贊助

在任何輸入框按 Ctrl+Alt+T，游標旁會出現一張半透明小卡片。 在卡片裡用你自己的語言打字，立即看到翻譯，按 Enter 把譯文回填到原本的輸入框。 不用切換視窗、不用複製貼上。

為什麼不直接攔截鍵盤？ 大多數同類工具用低階鍵盤掛鉤攔截打字，這會讓 中文／日文／韓文輸入法無法組字。PopLingo 改為「卡片本身即輸入面」， 因此注音、拼音都能正常使用。

驗證下載檔（選用）

certutil -hashfile PopLingo.exe SHA256

把輸出與 SHA256SUMS.txt 比對，一致即表示檔案完整。

可攜模式：在 PopLingo.exe 旁建立一個空檔案 portable.flag， 設定就會存在程式資料夾內，不寫入 %APPDATA%。

特色

  • 全域熱鍵：Ctrl+Alt+T 隨時開關，可自訂
  • 支援中文輸入法：注音、拼音皆可正常組字
  • 極簡卡片：半透明、緊貼文字游標、隨內容自動縮放、可拖曳
  • 翻譯風格：學術（預設）、商務、閒聊
  • 第二外語條件翻譯：原文已是目標語言時，改翻成第二語言
  • 切換輸入框自動跟隨：點另一個輸入框，卡片與回填目標一起更新
  • 多螢幕支援：含不同解析度、不同縮放比例、左側／上方螢幕（負座標）
  • 可完全離線：搭配 Ollama 本地模型，資料不出你的電腦
  • 外觀可調：字級、顏色、透明度
  • 開源：MIT 授權，單一 Python 檔，可自行稽核

快速開始

  1. 下載 PopLingo-win64.zip，解壓到任意資料夾
  2. 執行 PopLingo.exe（系統匣會出現圖示）
  3. 設定翻譯引擎（見下一節）
  4. 點任意輸入框 → 按 Ctrl+Alt+T → 打字 → Enter

按鍵說明

按鍵功能
Ctrl+Alt+T開啟 / 關閉翻譯模式
Ctrl+Alt+C把焦點拉回卡片（焦點跑到別的視窗時用）
Enter翻譯回填到輸入框（卡片清空後再按 = 送出）
Ctrl+Enter只回填、不送出
Ctrl+Shift+Enter回填原文
Shift+Enter換行
Esc取消、清空卡片

設定翻譯引擎

PopLingo 使用 OpenAI 相容的 API，任何支援 /chat/completions 的服務都能用。 設定方式：系統匣圖示右鍵 → 設定。

選項 A：DeepSeek（推薦，便宜且中文好）

  1. 到 platform.deepseek.com 註冊
  2. 左側「API keys」→ 建立新的金鑰，複製起來
  3. PopLingo 設定填入：
    欄位值
    API 網址https://api.deepseek.com
    API Key剛才複製的金鑰
    模型deepseek-flash（便宜快速）
    或 deepseek-v4-pro（品質較高）
  4. 按「儲存」，回到卡片打字測試

DeepSeek 為付費服務，費用依用量計價（翻譯用量極小，通常每月數元台幣等級）。

完全本地部署（Ollama）

不想把內容送到雲端？用 Ollama 在本機跑模型， 免費、離線、資料完全不出你的電腦。

步驟

  1. 到 ollama.com/download 下載並安裝 Ollama
  2. 開啟命令提示字元，下載一個模型（約 4–6 GB，只需一次）： 
    ollama pull qwen2.5:7b
  3. 確認服務在執行（安裝後會常駐於系統匣）： 
    ollama list
  4. PopLingo 設定填入：
    欄位值
    API 網址http://localhost:11434
    API Keyollama（本地不需驗證，隨便填即可）
    模型qwen2.5:7b

模型選擇建議

模型記憶體需求說明
qwen2.5:3b約 4 GB最輕量，翻譯品質尚可
qwen2.5:7b約 8 GB推薦，品質與速度平衡
qwen2.5:14b約 16 GB品質更好，需較強硬體
gemma3:4b約 5 GB多語支援不錯

注意：本地模型首次回應較慢（需載入模型到記憶體），且翻譯品質通常略遜於 DeepSeek / GPT 等雲端模型。適合注重隱私、或不想付費的使用者。

常見問題

Windows 顯示「不明的發行者」或 SmartScreen 警告？

因為本專案未購買程式碼簽章憑證。這是所有免費開源軟體的共同情況，並非病毒。 你可以：點「更多資訊」→「仍要執行」；或自行從原始碼建置（build.bat）， 以確保執行檔與原始碼一致。也可用上面的 SHA256 驗證下載檔。

需要付費嗎？

程式本身完全免費開源。翻譯費用取決於你選擇的引擎：雲端 API 依用量計費 （翻譯用量很小）、Ollama 本地模型完全免費。

翻譯內容會被上傳嗎？

只有你輸入的文字會送到你自己設定的 API。本程式不收集任何資料、 不含任何追蹤或統計。使用 Ollama 本地模型時，內容完全不會離開你的電腦。

支援 macOS / Linux 嗎？

目前僅支援 Windows 10 / 11（64 位元），因為大量使用 Windows 專屬 API。

原本的輸入框會被影響嗎？

不會。PopLingo 不攔截、不修改你的輸入框。你點輸入框、用 Backspace 編輯、 按 Enter 送出，全都照常運作。要做翻譯時才在卡片裡打字。

系統匣圖示找不到？

Windows 預設會把新的系統匣圖示收進「隱藏的圖示」區。點工作列右側的 ^ 符號，把 PopLingo 圖示拖到工作列上固定。

怎麼關閉啟動時自動檢查更新？

設定檔（%APPDATA%\PopLingo\config.json）把 check_update_on_start 改成 false。
