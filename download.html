驗證下載檔（選用）

在命令提示字元執行：

certutil -hashfile LinLingo-win64.zip SHA256

把輸出與 SHA256SUMS.txt 的內容比對，一致即表示檔案完整未被修改。

安裝方式

  1. 解壓 LinLingo-win64.zip 到任意資料夾（例如 C:\Tools\LinLingo）
  2. 執行 LinLingo.exe
  3. 系統匣（工作列右下角）會出現 LinLingo 圖示
  4. 右鍵圖示 →「設定」→ 填入翻譯引擎資訊（見 翻譯引擎設定）

如果系統匣圖示找不到，Windows 預設會把它收進「隱藏的圖示」區。 點工作列右側的 ^ 符號，把 LinLingo 圖示拖到工作列上固定。

可攜模式

預設設定檔存在 %APPDATA%\LinLingo\config.json，更新程式不會遺失。 若想把設定帶著走（例如放進 USB 隨身碟），在 LinLingo.exe 旁建立一個空檔案 portable.flag，設定就會改存在程式資料夾內。

下載疑難

點了按鈕卻沒有開始下載？

按鈕連到 GitHub Releases 的檔案。若你的網路環境阻擋 GitHub， 可以改用 Releases 頁面手動選擇檔案， 或使用 proxy。

Windows 顯示「不明的發行者」或 SmartScreen 警告？

因為本專案未購買程式碼簽章憑證。這是所有免費開源軟體的共同情況，並非病毒。 你可以：點「更多資訊」→「仍要執行」；或自行從原始碼建置， 以確保執行檔與原始碼一致。也可以用上面的 SHA256 驗證下載檔。

防毒軟體誤判？

PyInstaller 打包的執行檔偶爾會被誤判。可先驗證 SHA256，或自行建置。
