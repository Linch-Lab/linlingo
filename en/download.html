Installation

  1. Unzip LinLingo-win64.zip anywhere (e.g. C:\Tools\LinLingo)
  2. Run LinLingo.exe
  3. A LinLingo icon appears in the system tray
  4. Right-click it → Settings → enter your translation engine details (see Setup)

If you can't find the tray icon, Windows hides new icons by default. Click the ^ arrow near the clock and drag the LinLingo icon onto the taskbar.

Portable mode

By default settings live in %APPDATA%\LinLingo\config.json, so updating never loses them. To keep settings next to the program instead (for example on a USB stick), create an empty file named portable.flag beside LinLingo.exe.

Troubleshooting

The button did nothing?

The button links directly to the file on GitHub Releases. If your network blocks GitHub, use the Releases page instead, or a proxy.

Windows shows "Unknown publisher" or a SmartScreen warning?

Because this project has no code-signing certificate. That is normal for all free open-source software and does not mean it is malware. You can click "More info" → "Run anyway", or build it yourself from source to be sure the binary matches the code. You can also verify the SHA256 checksum above.

Antivirus flags it?

PyInstaller binaries are occasionally false-flagged. Verify the SHA256 or build from source.
