Frequently asked questions

Install and run

Windows says "Unknown publisher" or shows a SmartScreen warning

Because this project has no code-signing certificate. That is normal for all free open-source software and does not mean it is malware. Click "More info" → "Run anyway", or build it yourself from source (build.bat) so you know the binary matches the code. You can also verify the file with SHA256 on the download page.

Do I need Python installed?

No. The ZIP bundles everything — just unzip and run LinLingo.exe. Python is only needed if you want to run or build from source.

My antivirus flags it

PyInstaller binaries are occasionally false-flagged; this is a well-known industry issue. Verify the SHA256 or build from source.

Is macOS or Linux supported?

No — Windows 10 / 11 (64-bit) only, because the program relies heavily on Windows APIs.

Using it

Why doesn't it just intercept my typing?

Most similar tools use a low-level keyboard hook, but that breaks CJK input method composition — IMEs need the real keystrokes to build characters. LinLingo instead makes the card itself the input surface, so Zhuyin, Pinyin and other IMEs work normally.

Does it interfere with the text box I was using?

No. LinLingo never hooks or modifies your text box. Clicking, editing with Backspace, pressing Enter to send — all keep working exactly as before. You only type in the card while translation mode is on.

I can't find the tray icon

Windows hides new tray icons by default. Click the ^ arrow near the clock and drag the LinLingo icon onto the taskbar to pin it.

Translation keeps failing

Check in order: is the API key correct, does the account have balance, is the network working. The status bar shows the specific error. If you use Ollama, make sure it is running (ollama list should show your models).

Can it translate whole documents?

It accepts multi-line input (Shift+Enter), but LinLingo is built for quick, in-context sentences. For long documents, use a dedicated translation service.

Cost and privacy

Does it cost anything?

The program itself is completely free and open source (MIT). Translation cost depends on the engine you pick: cloud APIs bill by usage (translation uses very little), and a local Ollama model is completely free.

Is my text uploaded anywhere?

Only the text you type is sent, and only to the API you configured yourself. LinLingo collects nothing, contains no tracking and no telemetry. With a local Ollama model, nothing leaves your computer.

Can I use it offline?

Yes, with a local Ollama model it works fully offline. Cloud APIs of course need a network connection.

Configuration

Where is the config file?

%APPDATA%\LinLingo\config.json — paste that into the File Explorer address bar. Settings survive updates and reinstalls.

How do I make it portable?

Create an empty file named portable.flag next to LinLingo.exe. Settings will then live in the program folder.

Can I change the hotkeys?

Yes — edit toggle_vk / toggle_mods (toggle) and focus_vk / focus_mods (focus the card) in the config file. Modifiers add up: ALT=1, CTRL=2, SHIFT=4, WIN=8. A graphical hotkey editor is on the roadmap.

How do I turn off the update check at startup?

Set check_update_on_start to false in the config file.

Is there an English UI?

The application UI is currently Traditional Chinese. An English UI is on the roadmap.

Other

Translation quality isn't great

Try a larger model (deepseek-v4-pro, qwen2.5:14b), switch the translation style, or set the source language explicitly instead of using "Auto detect".

Can I use it commercially?

Yes. The MIT license allows use, modification and distribution, including commercial use.

Found a bug or want a feature?

Please open an issue. Include your Windows version, the LinLingo version, and the application where the problem occurs (especially if it only happens in one app).
