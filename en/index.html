Say what you mean, in any language

Press Ctrl+Alt+T in any text box and a small translucent card appears next to your caret. Type in your own language, see the translation instantly, then press Enter to insert it into the box you were already using. No switching windows, no copy-paste.

Why doesn't it hook your keyboard? Most similar tools use a low-level keyboard hook to intercept typing, and that breaks Chinese, Japanese and Korean IME composition — IMEs need the real keystrokes to build characters. LinLingo instead uses the card itself as the input surface, so Zhuyin, Pinyin and others work normally.

Quick start

  1. Download and unzip LinLingo-win64.zip
  2. Run LinLingo.exe — a tray icon appears
  3. Set up a translation engine (your own API key, or a free local model)
  4. Click any text box → press Ctrl+Alt+T → type → Enter
