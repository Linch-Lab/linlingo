常見問題

安裝與執行

Windows 顯示「不明的發行者」或 SmartScreen 警告？

因為本專案未購買程式碼簽章憑證。這是所有免費開源軟體的共同情況，並非病毒。 你可以：點「更多資訊」→「仍要執行」；或自行從原始碼建置（build.bat）， 以確保執行檔與原始碼一致。也可以到 下載頁用 SHA256 驗證檔案。

需要安裝 Python 嗎？

不需要。下載的 ZIP 已經包含執行環境，解壓後直接執行 LinLingo.exe 即可。 只有想自己從原始碼執行或建置時才需要 Python。

防毒軟體說有毒？

PyInstaller 打包的執行檔偶爾會被誤判，這是業界常見的假警報。 可以先用 SHA256 驗證檔案，或自行從原始碼建置。

支援 macOS / Linux 嗎？

目前僅支援 Windows 10 / 11（64 位元），因為大量使用 Windows 專屬 API。

使用

為什麼不直接攔截鍵盤輸入？

大多數同類工具用低階鍵盤掛鉤攔截打字，但這會讓 中文／日文／韓文輸入法無法組字——因為輸入法需要收到實體按鍵才能組字。 LinLingo 改為「卡片本身就是輸入框」，因此注音、拼音都能正常使用。

原本的輸入框會被影響嗎？

不會。LinLingo 不攔截、不修改你的輸入框。 你點輸入框、用 Backspace 編輯、按 Enter 送出，全都照常運作。 只有在你按 Ctrl+Alt+T 開啟翻譯模式後，才改在卡片裡打字。

系統匣圖示找不到？

Windows 預設會把新的系統匣圖示收進「隱藏的圖示」區。 點工作列右側的 ^ 符號，把 LinLingo 圖示拖到工作列上固定。

翻譯一直失敗怎麼辦？

依序檢查：API Key 是否正確、帳戶餘額是否足夠、網路是否暢通。 程式狀態列會顯示具體錯誤訊息。若使用 Ollama，確認 Ollama 正在執行 （ollama list 能列出模型）。

可以翻譯整段文章嗎？

可以，卡片支援多行輸入（Shift+Enter 換行）。 不過 LinLingo 是為「即時短句翻譯」設計的，長文建議用專門的翻譯服務。

費用與隱私

需要付費嗎？

程式本身完全免費開源（MIT）。翻譯費用取決於你選擇的引擎： 雲端 API 依用量計費（翻譯用量很小）、Ollama 本地模型完全免費。

翻譯內容會被上傳嗎？

只有你輸入的文字會送到你自己設定的 API。 LinLingo 本身不收集任何資料、不含任何追蹤、不含任何統計上報。 使用 Ollama 本地模型時，內容完全不會離開你的電腦。

可以離線使用嗎？

可以，搭配 Ollama 本地模型就完全離線。 使用雲端 API 時則需要網路。

設定與自訂

設定檔在哪裡？

%APPDATA%\LinLingo\config.json（把這串貼到檔案總管網址列即可開啟）。 更新或重裝程式都不會遺失設定。

怎麼改成可攜模式？

在 LinLingo.exe 旁建立一個空檔案 portable.flag， 設定就會改存在程式資料夾內。

可以改熱鍵嗎？

可以，編輯設定檔中的 toggle_vk / toggle_mods（開關） 與 focus_vk / focus_mods（焦點回卡片）。 修飾鍵相加：ALT=1、CTRL=2、SHIFT=4、WIN=8。 圖形化的熱鍵設定介面還在開發中。

怎麼關閉啟動時自動檢查更新？

設定檔裡把 check_update_on_start 改成 false。

可以改成別的語言介面嗎？

目前介面為繁體中文。英文介面列在後續開發清單中。

其他

翻譯品質不好？

可以試試：換用較大的模型（例如 deepseek-v4-pro 或 qwen2.5:14b）、 切換翻譯風格、或在設定裡明確指定來源語言（不要用「自動偵測」）。

可以拿來做商業用途嗎？

可以。MIT 授權允許自由使用、修改、散布，包含商業用途。

發現 bug 或想許願新功能？

歡迎到 GitHub Issues 回報。 回報時請附上 Windows 版本、LinLingo 版本，以及發生問題的應用程式名稱（若特定應用才有問題）。
