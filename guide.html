使用說明

LinLingo 的設計目標是「不要打斷你」——不搶走輸入框、不改變你原本的打字習慣。

操作流程

  1. 點擊任何應用程式的輸入框（聊天框、表單、搜尋欄…），定位文字游標
  2. 按 Ctrl+Alt+T，一張半透明卡片會出現在目前螢幕中央並取得焦點
  3. 直接在卡片打字（中文輸入法可正常組字），翻譯會即時出現
  4. 按 Enter 把譯文回填到原本的輸入框
  5. 卡片清空後再按一次 Enter，等同在輸入框按 Enter（送出）
  6. 再按 Ctrl+Alt+T 關閉翻譯模式

按鍵說明

按鍵功能
Ctrl+Alt+T開啟 / 關閉翻譯模式
Ctrl+Alt+C把焦點拉回卡片（焦點跑到別的視窗時用）
Ctrl+Alt+Enter隨處插入譯文（焦點不在卡片時用，例如 PowerPoint）
Enter回填翻譯；卡片清空後再按 = 送出
Ctrl+Enter只回填、不送出
Ctrl+Shift+Enter回填原文（不翻譯）
Shift+Enter換行（輸入多行訊息）
Esc取消、清空卡片

關於 Ctrl+Alt+C

當你在別的輸入框點來點去之後，焦點就離開卡片了。 這時不用去尋找卡片在哪，按 Ctrl+Alt+C 焦點就會跳回卡片，可以繼續打字。 （這個熱鍵可以在設定檔中更改。）

浮動卡片

  • 開啟時置中：卡片會出現在你目前所在螢幕的正中央，不是滑鼠位置
  • 隨內容縮放：字打越多，卡片自動變大
  • 可拖曳：拖曳卡片頂端的細條或譯文區即可移動
  • 半透明：不會完全擋住後面的內容
  • 拖過就固定：拖到你喜歡的位置後，之後開啟都回到那裡，打字時不會自己跳動
  • 可重置：系統匣圖示右鍵 →「卡片位置歸中」可回到螢幕中央

卡片外觀可調整

系統匣圖示右鍵 →「設定」→「卡片外觀」分頁，可以調整：

  • 字級與顏色：輸入文字與翻譯文字可分別設定
  • 卡片底色：點色塊開啟調色盤，外框線會自動配色
  • 不透明度：30%～100%，卡片不會完全擋住後面的內容
  • 圓角：0（直角）～40 像素，預設 14

上方有即時預覽，調整立刻看到結果。

系統匣圖示

啟動後，工作列右下角（通知區域）會出現 LinLingo 圖示：

狀態外觀
翻譯模式開啟圖示點亮（藍色）
翻譯模式關閉圖示反灰

在圖示上按右鍵可以開啟選單：

  • 設定 —— 翻譯服務、語言、風格、卡片外觀
  • 使用說明 —— 就是你現在看的這一頁（程式內版本）
  • 贊助 —— 開啟贊助頁面
  • 檢查更新 —— 手動檢查是否有新版本
  • 退出 —— 完全關閉程式

關閉程式的說明視窗不會結束程式，只是隱藏。要真的結束請用選單的「退出」。

翻譯風格

風格適用
學術（預設）正式、嚴謹。原文結尾沒有句號時會視為標題，採標題式翻譯。
商務商務、專業、禮貌的正式語氣。
閒聊口語化、自然流暢的聊天語氣。

第二外語（條件翻譯）

設定裡有一個「第二外語」欄位。它的行為是：

原文語言翻譯結果
不是目標語言（例如中文）翻成目標語言（例如英文）
已經是目標語言（例如英文）翻成第二外語（例如德文）

例如設定「目標語言：英文」+「第二外語：德文」之後， 打中文會得到英文，打英文會得到德文。不是一次翻成兩種語言。 若不需要這個功能，把第二外語設為「（無）」即可。

疑難排解

程式啟動了但沒有反應

確認系統匣有圖示。翻譯模式要按 Ctrl+Alt+T 才會開啟。

熱鍵沒反應

可能有其他程式佔用了 Ctrl+Alt+T。可在設定檔 %APPDATA%\LinLingo\config.json 更改熱鍵。

翻譯一直失敗

先確認 API Key 是否正確（見 翻譯引擎設定）， 再看程式狀態列的錯誤訊息。常見錯誤：金鑰錯誤、餘額不足、網路不通。

回填貼到錯的位置

回填前不要切換視窗。若失敗，譯文已經在剪貼簿裡，可以手動 Ctrl+V。

想關掉啟動時自動檢查更新

設定檔裡把 check_update_on_start 改成 false。
