在別的語言裡，也能好好說話

在任何輸入框按 Ctrl+Alt+T，畫面中央會出現一張半透明小卡片。 在卡片裡用你自己的語言打字，立即看到翻譯，按 Enter 把譯文回填到原本的輸入框。 不必切換視窗、不必複製貼上。

下載 LinLingo（Windows 64 位元）
免安裝 ZIP ｜ 解壓即用，不需安裝 Python
其他下載選項與檔案驗證 · 翻譯引擎設定教學

為什麼不攔截鍵盤？ 大多數同類工具用低階鍵盤掛鉤攔截打字，這會讓中文／日文／韓文輸入法無法組字。 LinLingo 改為「卡片本身即輸入面」，因此注音、拼音都能正常使用。

實際操作

在 Word 中輸入中文 → 譯文即時出現 → 按 Enter 回填到文件。

快速開始

  1. 下載並解壓 LinLingo-win64.zip
  2. 執行 LinLingo.exe（系統匣會出現圖示）
  3. 設定翻譯引擎（填 API Key，或改用免費的本地模型）
  4. 點擊任意輸入框 → 按 Ctrl+Alt+T → 打字 → Enter

更完整的操作與按鍵說明，請看 使用說明。
