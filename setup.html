翻譯引擎設定

LinLingo 使用 OpenAI 相容的 API，任何支援 /chat/completions 的服務都能用。 只要在設定裡選一個服務、貼上自己的金鑰即可。

設定位置

系統匣圖示右鍵 →「設定」→「翻譯」分頁。

欄位說明
翻譯服務下拉選單。選好之後 API 網址與模型清單會自動帶入。
API 網址可手動修改（選「自訂…」時使用）。
API Key你向服務商申請的金鑰。
模型下拉選單，也可自行輸入服務商提供的最新模型名稱。
取得 API Key按鈕，會開啟該服務的申請頁面。

選項 A：DeepSeek（推薦）

中文翻譯品質好、價格低，是目前最推薦的選擇。

  1. 到 platform.deepseek.com 註冊
  2. 左側選「API keys」→ 建立新的金鑰，複製起來
  3. LinLingo 設定裡填入：
    欄位值
    翻譯服務DeepSeek
    API 網址https://api.deepseek.com
    模型deepseek-flash（便宜快速）
    或 deepseek-v4-pro（品質較高）
  4. 按「儲存」，回到卡片打字測試

DeepSeek 為付費服務，依用量計價。翻譯的 token 用量很小，一般使用每月花費極低。

選項 C：完全本地部署（Ollama）

不想把內容送到雲端？用 Ollama 在本機執行模型， 免費、離線、資料完全不出你的電腦。

步驟

  1. 到 ollama.com/download 下載並安裝 Ollama
  2. 開啟命令提示字元，下載一個模型（約 4–6 GB，只需一次）： 
    ollama pull qwen2.5:7b
  3. 確認模型已下載： 
    ollama list
  4. LinLingo 設定填入：
    欄位值
    翻譯服務Ollama（本地）
    API 網址http://localhost:11434/v1
    API Keyollama（本地不驗證，隨便填即可）
    模型qwen2.5:7b

模型選擇建議

模型記憶體需求說明
qwen2.5:3b約 4 GB最輕量，翻譯品質尚可
qwen2.5:7b約 8 GB推薦，品質與速度平衡
qwen2.5:14b約 16 GB品質更好，需較強硬體
gemma3:4b約 5 GB多語支援不錯

注意：本地模型首次回應較慢（需要先把模型載入記憶體）， 翻譯品質通常也略遜於 DeepSeek、GPT 等雲端模型。 適合注重隱私、或不想付費的使用者。

LM Studio

也可以使用 LM Studio： 在軟體中啟動本機伺服器後，設定裡選「LM Studio（本地）」， API 網址為 http://localhost:1234/v1。

語言與風格

欄位說明
來源語言預設「自動偵測」，交給模型判斷。
目標語言預設「英文」。
第二外語原文已是目標語言時改翻成此語言。選「（無）」＝停用。 詳細行為見 使用說明。
翻譯風格學術（預設）／商務／閒聊。
延遲（毫秒）停止輸入後多久開始翻譯，預設 500。

隱私

只有你輸入的文字會送到你自己設定的 API。 LinLingo 本身不收集任何資料、不含任何追蹤或統計。 使用 Ollama 本地模型時，內容完全不會離開你的電腦。
